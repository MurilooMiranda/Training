# C# Training

This repository contains a collection of programming exercises developed to improve my problem-solving skills and strengthen my knowledge of C#.

The exercises are organized into different difficulty levels, allowing the practice to evolve from fundamental programming concepts to more complex problems and data structures.

## Structure

```text
Training/
├── basic/
├── intermediate/
└── advanced/       # Future
```

### Basic

The **Basic** level focuses on fundamental programming concepts and syntax.

The goal is to build a solid foundation in C# by practicing topics such as:

* Variables and data types
* Input and output
* Conditional statements
* Loops
* Methods
* Basic arrays
* Simple problem solving

The exercises at this stage are mainly focused on understanding the language and developing basic programming logic.

### Intermediate

The **Intermediate** level introduces more challenging problems that require combining multiple programming concepts.

The focus is on developing problem-solving skills and learning how to choose appropriate data structures and algorithms for each problem.

Topics include:

* Arrays and lists
* Strings
* Stacks and queues
* Dictionaries
* Searching and sorting
* Frequency counting
* Algorithmic problem solving

The goal is not only to solve the problems, but also to understand **why a particular data structure or approach is appropriate for each situation**.

See the [Intermediate README](./intermediate/README.md) for the complete list of challenges.

### Advanced

The **Advanced** level will be added in the future.

It will focus on more complex algorithms, data structures, optimization, and problems that require a deeper understanding of software engineering and algorithmic thinking.

## Purpose

This repository is primarily a personal training environment.

The objective is to practice consistently, identify weaknesses, and improve my ability to design and implement solutions in C#.

The difficulty levels are intended to represent a progression in problem-solving complexity rather than simply the complexity of the C# syntax.
