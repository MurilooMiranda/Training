# C# Training

This repository is a personal training environment focused on preparing for **technical interviews and live coding challenges**.

The goal is not to learn programming from scratch, but to strengthen programming fundamentals, improve problem-solving speed, and become more comfortable writing solutions under interview conditions.

The exercises are organized progressively, starting with fundamental concepts and moving toward more complex data structures and algorithms.

## Structure

```text
Training/
├── basic/
├── intermediate/
└── advanced/       # Future
```

### Basic

The **Basic** level is a deliberate review of fundamental programming concepts.

Although these topics are already familiar to me, revisiting them helps improve coding speed, accuracy, and fluency when solving problems without relying heavily on external references.

The focus is on:

* Programming fundamentals
* C# syntax
* Control flow
* Arrays and strings
* Methods
* Basic problem solving

The purpose of this stage is to build the speed and confidence needed to handle simpler problems during live coding interviews.

### Intermediate

The **Intermediate** level introduces problems that require more structured reasoning and the appropriate use of data structures and algorithms.

The focus is on:

* Arrays and Lists
* Strings
* Stacks
* Queues
* Dictionaries
* HashSets
* Searching
* Sorting
* Frequency counting
* Basic algorithmic complexity

The goal is to develop the ability to recognize which data structure or approach is most appropriate for a given problem, while also improving implementation speed.

See the [Intermediate README](./intermediate/README.md) for the complete list of challenges.

### Advanced

The **Advanced** level will be added in the future.

It will focus on more complex data structures, algorithms, optimization, and problems closer to the difficulty expected in more demanding technical interviews.

## Purpose

This repository is part of my preparation for **technical interviews, coding challenges, and live coding sessions**.

The main objectives are to:

* Improve problem-solving speed
* Strengthen algorithmic thinking
* Practice choosing appropriate data structures
* Become more fluent writing C# without relying on autocomplete or external references
* Practice explaining and implementing solutions under time constraints
* Identify and improve weaknesses in programming fundamentals

The difficulty levels represent the **complexity of the problems being practiced**, not my overall programming experience.

The intention is to turn concepts I already know into skills that I can apply **quickly, clearly, and confidently during a live coding interview**.
