# Basic

The **Basic** level focuses on building a solid foundation in programming and C# fundamentals.

The exercises in this stage are designed to develop basic programming logic and familiarity with the language before moving on to more complex problems and data structures.

The main topics covered are:

* Variables and Data Types
* Input and Output
* Conditional Statements
* Loops
* Methods
* Arrays
* Strings
* Basic Problem Solving

## Exercises

The exercises in this level cover fundamental programming problems, such as:

1. Basic Input and Output
2. Conditional Logic
3. Loops and Repetition
4. Number Manipulation
5. String Manipulation
6. Arrays
7. Methods and Functions
8. Basic Validation
9. Simple Calculations
10. Basic Problem Solving

The goal of this stage is to build a strong foundation in programming logic and C# before progressing to more complex data structures and algorithms.
