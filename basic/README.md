# Basic

This repository aims to practice basic problem-solving skills using C#. The
exercises cover input and output, mathematical operations, conditional
statements, loops, strings, arrays, collections, and simple algorithms.

## Implemented problems

The problems below are implemented in
[`basic/Program.cs`](./basic/Program.cs) and can be run individually through
the program's interactive menu.

1. **Sum** — reads two numbers and displays their sum.
2. **Average** — calculates the average of three numbers.
3. **Temperature** — converts a temperature from Celsius to Fahrenheit.
4. **Circle area** — calculates the area of a circle from its radius.
5. **Change** — checks a product payment and calculates the change.
6. **Number sign** — identifies whether a number is positive, negative, or zero.
7. **Compare three numbers** — finds the largest of three numbers.
8. **Parity** — checks whether a number is even or odd.
9. **Approval** — calculates the average of two grades and reports whether the student passed.
10. **Leap year** — checks whether a year is a leap year.
11. **Count to N** — displays the numbers from 1 to a specified limit.
12. **Sum to N** — calculates the sum of the numbers from 1 to a specified limit.
13. **Multiplication table** — displays the multiplication table of a number.
14. **Sum even numbers** — sums the even numbers from 1 to a specified limit.
15. **Factorial** — calculates the factorial of a number.
16. **Character count** — counts the characters in a string.
17. **Vowels** — counts the vowels in a string.
18. **Reverse string** — reverses the characters in a string.
19. **Palindrome** — checks whether a string is a palindrome.
20. **Repeated character** — identifies a repeated character in a string.
21. **Array maximum** — finds the largest value in an array.
22. **Array average** — calculates the average of the values in an array.
23. **Reverse array** — reverses the order of the values in an array.
24. **Remove duplicates** — removes duplicate values from an array.
25. **Second largest** — finds the second-largest value in an array.
26. **Prime** — checks whether a number is prime.
27. **Maximum** — compares two numbers and identifies the larger one.
28. **Validate password** — checks whether a password has a minimum length,
    uppercase letters, lowercase letters, and digits.
29. **Statistics** — displays the largest value, smallest value, and average of an array.
30. **Frequency** — counts the frequency of each number in an array.
31. **First unique character** — finds the first character that appears only
    once in a string.
32. **Common elements** — finds matching elements in two sequences of numbers.
33. **Two sum** — finds pairs of elements whose sum matches a target value.
34. **Group anagrams** — groups words that are anagrams of one another.

## How to run

The .NET SDK must be installed. To run the basic project, use:

```bash
dotnet run --project basic/basic.csproj
```

Then, choose an option from the menu to run the desired problem.
