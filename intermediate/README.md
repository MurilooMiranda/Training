# Intermediate

The **Intermediate** level focuses on solving problems that require more structured reasoning and a better understanding of data structures.

The exercises in this stage are designed to move beyond basic programming logic and encourage the use of appropriate data structures and algorithms to solve each problem.

The main topics covered are:

* Arrays and Lists
* Strings
* Stacks
* Queues
* Dictionaries
* HashSets
* Searching
* Sorting
* Frequency counting
* Basic algorithmic complexity

## Exercises

1. Balanced Parentheses
2. Reverse a String Using a Stack
3. First Non-Repeating Character
4. Queue Simulation
5. Number Frequency Counter
6. Remove Duplicates While Preserving Order
7. Two Sum
8. Palindrome Checker
9. Browser History
10. Group Anagrams

The goal of this stage is not only to solve the exercises, but to develop the ability to recognize **which data structure and approach are most appropriate for each problem**.
